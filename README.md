This is my first ever portfolio website, built from scratch using pure HTML, CSS, and JavaScript. This was  a way to showcase my projects, certifications, and growing skills in cybersecurity and IT.

The site features a dark, terminal-inspired design — fitting for someone diving into cybersecurity. It includes sections for my bio, projects, skills, and contact information, along with a working JavaScript-powered project slider and scroll animations.

It's not the fanciest portfolio out there. But it's mine, it works, and it represents a huge milestone in my coding journey. I've since built a newer portfolio that reflects how much I've grown as a developer, but this first version will always have a special place in my heart.
